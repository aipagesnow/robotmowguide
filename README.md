# RobotMowGuide.com

Amazon Associates affiliate website focused on high-ticket robotic lawn mowers.

## Domain
- **Primary**: robotmowguide.com (secured)
- Hosting: Vercel (import from this GitHub repo)
- Framework: Astro (recommended for static content sites, excellent Core Web Vitals, SEO, and speed)

## Niche
Robotic / autonomous lawn mowers and related high-ticket accessories. High AOV, growing market, strong buyer intent, good commission potential on Lawn & Garden category.

## Goals
- Rank quickly for commercial and informational keywords around robotic mowers
- Drive SEO traffic via hub-and-spoke / pillar-cluster architecture
- High conversion on money pages (comparisons, roundups, reviews) with clear CTAs, tables, and trust signals
- Original images only (no Amazon API / unauthorized product images)
- Compliant affiliate disclosures

## Tech Stack
- Astro
- Tailwind CSS (or similar)
- Vercel deployment from GitHub
- Markdown/MDX for content
- Schema.org markup (Review, Product, FAQ, etc.)
