# Affiliate Compliance Notes

## Amazon Associates Requirements
- Clear and conspicuous disclosure that the site is part of the Amazon Associates program on every page that contains affiliate links (footer is common and acceptable if prominent).
- Example disclosure: "As an Amazon Associate I earn from qualifying purchases."
- Do not use Amazon trademarks or logos in ways that imply endorsement beyond the program.
- Do not use Amazon product images without proper authorization (hence original images).
- Links should be proper affiliate links (you will generate these once approved for the program).
- No cookie stuffing or other prohibited practices.

## Best Practices
- Place disclosure near the top of money pages or in a sticky footer.
- Be transparent in reviews (pros and cons).
- Update content if products change significantly.
- Track which links convert.

## Implementation
- Add disclosure component that appears site-wide in the footer.
- Optional per-page disclosure banner on review/comparison pages.
