# Image Guidelines

## Policy
All images must be original or properly licensed. No direct scraping of Amazon product images.

## Recommendations
- Hero images of robotic mowers in realistic lawn settings
- Clean product-style renders or photos that closely match real models (color, shape, form factor)
- Diagrams for setup, navigation zones, lawn size guides
- Comparison visuals
- Consistent branding (colors, style) across the site
- Optimized formats (WebP preferred) and sizes for performance
- Descriptive alt text for SEO and accessibility

## Generation Tips (for Grok Build / image tools)
- Prompt style: "Photorealistic robotic lawn mower [model description] on a green lawn, soft daylight, high detail, no text, professional product photography style"
- Create variants for different angles or lawn sizes
- Use consistent lighting and composition

## File Organization
- Store in `public/images/` or `src/assets/images/`
- Naming: descriptive, kebab-case (e.g. `segway-navimow-x3-hero.webp`)
