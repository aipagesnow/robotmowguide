# Astro Setup Notes

## Recommended Init
```bash
npm create astro@latest
# Choose: Empty or Blog template, TypeScript, Tailwind, etc.
```

## Suggested Packages
- @astrojs/tailwind
- @astrojs/sitemap
- @astrojs/mdx (for richer content)
- Optional: astro-seo or similar for meta

## Content Collections
Use Astro Content Collections for:
- Reviews
- Guides
- Products data

## Config Highlights
- Site URL: https://robotmowguide.com
- Trailing slash preference
- Image optimization via Astro

## Performance Goals
- Mostly static pages
- Minimal client-side JS
- Excellent Lighthouse scores
