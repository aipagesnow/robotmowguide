# SEO Checklist for RobotMowGuide.com

## On-Page
- Unique, compelling title tags and meta descriptions for every page (include primary keyword + brand)
- Proper H1, H2, H3 hierarchy
- Keyword in URL slug where natural
- Internal linking from cluster content to pillar and money pages
- Alt text on all images (descriptive, include keyword where relevant)
- Schema markup: Article, Review, Product, FAQPage, BreadcrumbList
- Fast loading (Astro static generation helps)
- Mobile-responsive
- Clear affiliate disclosure

## Content
- Pillar page as the main ranking asset for "best robotic lawn mowers"
- Supporting guides targeting long-tail queries
- Regular updates to keep content fresh (especially pricing/models)
- Original images and unique analysis
- E-E-A-T signals: about page, author info if possible, clear methodology

## Technical
- Sitemap.xml (Astro can generate)
- robots.txt
- Canonical tags
- Open Graph / Twitter cards
- Core Web Vitals optimized (minimize JS, optimize images)
- Clean URL structure

## Off-Page (later)
- Outreach for backlinks from relevant lawn/gardening sites
- Social sharing
