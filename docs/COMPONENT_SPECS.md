# Component Specs

## Core Components to Build

### ComparisonTable
- Columns: Model, Image, Price Range, Lawn Size, Key Features, Rating, CTA button
- Badges: Best Overall, Best Value, Best for Small Lawns, etc.
- Responsive (stack or scroll on mobile)
- Sortable or filterable if feasible

### ProductCard
- Image
- Name + short tagline
- Key specs (3–4 bullets)
- Pros/cons mini
- Affiliate CTA button
- Link to full review

### ProsCons
- Two-column layout
- Green check / red x icons

### AffiliateCTA
- Prominent button or banner
- "Check Price on Amazon" style text
- Disclosure nearby

### Disclosure
- Footer component + optional page-level

### FAQ
- Accordion style for schema and UX

### Layout
- Header with logo (Robot Mow Guide) + nav
- Footer with links, disclosure, copyright

Use Astro components or islands as needed. Keep JS minimal for performance.
